# showipmac Sprach- und Hilfepakete

`catalog.json` und die acht JSON-Pakete werden gemeinsam veröffentlicht.
Die Pakete enthalten vollständig übersetzte Oberflächenschlüssel und jeweils
Offline-HTML-Hilfe. Sie identifizieren ausschließlich `showipmac`.
Lizenz: GPL-3.0-only; vollständiger Text in LICENSE. Autor: Josef.

Basisadresse nach Veröffentlichung:
https://raw.githubusercontent.com/Lehner-007/showipmac/main/github/sprachpakete

In showipmac: Einstellungen → Sprachen installieren → Sprache und Hilfe nachladen.
Eigene Pakete lassen sich dort lokal importieren. DE/EN bleiben im Basispaket.
Eine muttersprachliche Prüfung der Übersetzungen steht aus.
